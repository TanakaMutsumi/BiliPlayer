# 哔哩播放器 BiliPlayer

一个 **Windows 桌面软件**：登录自己的B站账号，把收藏夹一键导入成歌单，也能搜索B站视频加进歌单；每首"歌"既可以**只听声音**（当音乐放），也可以随时**看视频**。界面按B站风格设计（粉白色系）。

## 启动方式

**桌面软件（推荐）**：双击桌面上的「哔哩播放器」快捷方式，或直接运行
`dist\BiliPlayer-win32-x64\BiliPlayer.exe`

> 软件是绿色便携版，整个 `dist\BiliPlayer-win32-x64` 文件夹可以拷到任何位置运行；删除该文件夹即卸载程序（**歌单和登录数据不受影响**，它们存放在 `C:\Users\16493\AppData\Roaming\BiliPlayer`，彻底清空数据需删除该文件夹）。
> 首次运行如 Windows SmartScreen 弹提示（未签名程序），点「更多信息 → 仍要运行」即可。旧版本（数据在 exe 旁 `data\`）升级后首次启动会自动把旧数据迁移到新位置。

其他启动方式（开发用）：

- `start.bat` —— 自动选择：优先启动打包软件 → 否则 electron 开发模式 → 否则网页模式
- `npm start` —— Electron 开发模式
- `npm run start:web` —— 纯网页模式（`node server.js`，浏览器打开 http://127.0.0.1:8899）
- `npm run dist` —— 重新打包成 exe（输出到 `dist/`）

## 使用流程

1. **登录**：左侧或右上角点「扫码登录」，用哔哩哔哩APP扫码确认即可。登录凭证（Cookie）只保存在本机软件目录的 `data\cookies.json`，不会上传到任何第三方。
2. **导入收藏**：「我的收藏」里会列出你**创建的**和**订阅的**收藏夹。点进任何一个收藏夹可以：
   - 勾选若干视频 →「加入歌单」（支持多选批量导入）；
   - 或直接「整夹导入歌单」一键生成歌单。
3. **搜索**：顶栏搜索框搜B站视频，结果页可播放、可加入歌单。
4. **UP主主页**：点击任意视频卡片、歌单列表或播放页里的 UP 名字，进入 TA 的投稿列表，可播放、可批量加入歌单。
5. **评论区**：播放页右侧「评论」标签页，按热度查看全部评论和楼中楼回复，可继续加载更多。
6. **听 / 看**：
   - 底部播放条上的 🎧 / 📺 两个按钮切换「纯听」和「看视频」模式，切换时保持进度；
   - 「看视频」模式下离开播放页，会出现右下角的迷你悬浮小窗，点「展开」回到播放页；
   - 空格键 播放/暂停，支持进度拖动、音量、列表循环/单曲循环/随机播放。
7. **歌单管理**：左侧栏管理所有歌单，支持新建、重命名、删除、拖拽排序、移除单曲。

## 目录结构

```
electron/main.js      Electron 主进程（应用窗口、单实例、外链转系统浏览器）
server.js             内嵌本地服务（B站接口代理 + 音视频流代理，仅监听 127.0.0.1）
src/bilibili.js       B站接口客户端（扫码登录/收藏夹/搜索WBI签名/播放地址解析/Cookie管理）
src/wbi.js            WBI 参数签名
public/               前端页面（原生 HTML/CSS/JS，无框架）
scripts/make-icon.js  应用图标生成脚本
assets/icon.ico       应用图标
dist/BiliPlayer-win32-x64/   打包成品（BiliPlayer.exe 及运行时，约 360MB）
data/                 网页模式的数据目录（软件版数据在 %APPDATA%\BiliPlayer）
```

## 实现说明 / 已知限制

- 音频走 B站 DASH 音频流（登录后最高 320kbps/Hi-Res，未登录 64kbps 起）；视频走 html5 mp4 通道（一般 720p，清晰度以B站下发的为准，大会员更高清晰度不在此通道内）。
- 音视频通过本地服务代理转发（自动带 Referer），所以播放、拖动进度都正常；该代理只允许B站CDN域名。
- B站**搜索接口必须登录后**才能用（未登录会提示扫码）。
- 暂不支持：多P视频选分P（默认播P1）、弹幕、充电专属/付费视频、大会员专属音质外的更多画质选项。
- 若B站接口日后调整导致某功能报错，把报错信息（弹toast会显示错误码）发出来即可针对性修。

## 隐私与安全

- 内嵌服务只监听本机 127.0.0.1，局域网内其他设备无法访问。
- 登录凭证与歌单仅存本机 `%APPDATA%\BiliPlayer`；删除该文件夹即退出登录并清空数据。
