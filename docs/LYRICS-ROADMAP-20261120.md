## 1. 当前状态一句话

歌词模块已经从“按标题搜一个 LRC”升级成：

```text
多源歌词（B站CC / 网易云 / 酷狗 / AMLL / LRCLIB）
  → 多身份标题解析 + 别名/标签证据
  → 逐字/行级/纯音乐识别
  → 逐字时间轴直接进 Folia/流光
  → 现场版 scale/offset 对齐（可撤销）

  → 候选源换源
```

## 2. 已完成能力

### 2.1 歌词来源

| 来源 | 能力 | 备注 |
|---|---|---|
| B 站本视频字幕 | 行级时间，天然对应本视频 | 需登录；适合现场版做锚点 |
| 网易云 LRC | 行级 + 翻译 + 罗马音 | `lrc/tlyric/romalrc` |
| 网易云 YRC | 逐字时间 | 有则优先 |
| 酷狗 KRC | 逐字 + `[language:]` 翻译/罗马音 | 解码简单，覆盖好 |
| AMLL TTML | 高质量逐字 + 翻译 | 按 NCM ID 取，国内镜像 |
| LRCLIB | 行级开放兜底 | 非中文/英文歌常用 |

### 2.2 匹配

- 多身份候选：同一标题生成多组 `歌名/歌手` 可能组合
- 搜索驱动仲裁：用搜索结果、标题、歌手、时长、版本证据打分
- 中文译名：NetEase `transNames/alias`
- 歌手不在标题里：B 站视频标签补充证据（如“夜鹿”标签里有 `ヨルシカ`）
- 版本词：live / tour / 再演 / cover / remix / instrumental
- 纯音乐：识别“纯音乐，请欣赏”占位
- 繁简/异体字兜底：`米津玄師` ↔ `米津玄师`

### 2.3 时间轴

- 逐字来源直接进入 Folia 的 `words[{startTime,endTime,text}]`
- 流光系样式优先使用真实 `line.words`，不再按字数插值
- `flowLineEnd` 不再按字数砍掉真实逐词行尾
- 行级来源仍保留插值 + AI 分词 + BPM 量化回退
- 现场版 `(scale, offset)` 对齐，低置信显示“低置信”，可“取消对齐”
- 手动偏移支持 `90` / `90.5` / `1:30`，范围 ±600s
- 手动偏移用 `baseLines` 绝对计算，负数/正数来回切换不会累积误差
- 切歌/重开：localStorage 本机优先 + 服务端串行写回
- 歌词列表滚动改为直接计算 `scrollTop`，修复 Electron 下 `scrollIntoView({behavior:'smooth'})` 失效
- 关键行打点 + 自动插值：相邻锚点间做局部线性映射，锚点范围外保持原偏移
- 日文 KRC `[kana:]` 逐字假名：按 KRC word 时间把假名贴到含汉字的词上，歌词列表用 `<ruby>` 显示；只对部分带 kana 的 KRC 生效
- 逐行置信度圆点：蓝=CC 直接匹配、黄=CC 未覆盖按偏移估算、红=自动对齐低置信；底部有图例，悬停有说明
- 置信度数据会跟着逐行偏移/自动对齐一起平移，不会丢

### 2.4 UI

- 歌词来源 + `逐字/行级` 徽标
- 翻译副行
- `−0.2s / 输入框 / 应用 / +0.2s / 归零`
- `取消对齐 / 换源 / 重新找`
- 低置信、全歌词越界、B 站未登录等提示
- 候选源弹窗：来源、标题、歌手、质量、时长、当前源
- 未命中原因卡片：登录 B 站 / 换源 / 导入歌词 / 重新找 / 诊断
- 歌词导入弹窗、导出弹窗（LRC / 增强 LRC / SRT / ASS）

### 2.5 稳定性

- NetEase `/web` 405 → 旧接口 → 匿名通道
- 登录 Cookie 风控时自动退匿名
- 查询预算：NetEase 最多 2 个关键词、酷狗最多 2 个关键词
- 超时上限：搜索 6s、歌词 8s、AMLL 3.5s
- 搜索结果内存缓存；歌词磁盘缓存 30 天
- 候选源持久化；手动偏移/对齐持久化
- 未命中负缓存 5 分钟
- 切歌歌词身份包含 `cid`：B 站条目先到 `bvid`、后补 `cid` 时会重新加载，不再显示上一首歌词
- B 站条目缺 `cid` 时先清空旧歌词并显示“搜索歌词中”，由歌词侧补 `cid` 后自动继续
- 手动导入歌词独立存 `data/lyric-overrides`，优先于在线源；清缓存不丢，整首偏移同步写回
- 换源锁定独立存 `data/lyric-locks`；逐行偏移同步存 `data/lyric-line-offsets`，本机优先、服务端兜底
- 未命中原因分类：B 站未登录 / 音源无结果 / 候选分数低 / 接口风控 / cid 获取失败 / 纯音乐

- 换源锁定写入 `data/lyric-locks/<key>.json`；清缓存/“重新找”后仍回到锁定源

#### 5.8 tap-to-sync（已完成 2026-11-21）
- 播放到每句开头按空格或“打点”
- 当前目标行钉到当前时间，自动前进到下一行
- 支持撤销上一个/完成；Esc 结束
- 与整首偏移、逐行 nudge 叠加，localStorage 持久化
- 空格在打点模式下不会触发播放/暂停
- 只打关键行后自动插值：相邻两个锚点之间按原歌词时间比例做局部线性映射
  （等价于局部 `scale + offset`），范围外的行保持原偏移
- 打点模式下点击任意歌词行可直接切换目标行，方便只补副歌/某一段
- 面板实时显示“已打 N 点”；完成时提示“插值 N 行”
- 实测：51 行逐字歌词，锚点第 3 行 +1.0s、第 8 行 +3.0s → 第 4–7 行自动得到
  1217 / 1660 / 2152 / 2591ms；撤销、重复打点、单锚点提示均正常

- 导出时间戳用厘秒/毫秒整数归一，`59.999s` 会正确进位到 `01:00.00`，不会出现 `00:60.00`

#### 5.10 歌词校准向导（已完成 2026-11-21）

- 歌手别名：夜鹿→ヨルシカ、真夜中→ずっと真夜中でいいのに。等；参与搜索身份和歌手证据

### P1：现场版与无歌词的“重武器”

#### 6.1 B 站 CC 时间锚定 + 外部文本 DP（已完成 2026-11-21）
这是最稳的现场版方案，不需要 ASR：

```text
本视频 CC 字幕（时间准，文本可能有错）
  + 外部正确歌词文本
  → 行级 DP 对齐
  → 得到“正确文本 + 本视频时间”
```

- CC 文本正确：直接用
- CC 文本有错：保留 CC 时间，替换为外部文本
- CC 只有部分段落：用 CC 锚点 + 外部 LRC 中位偏移插值
- **CC 是中文翻译、外部歌词是日文原文**：同时比较外部正文和 `translation`；严格匹配失败时用“翻译 + 位置先验”的宽松通道（实测 `又三郎` CC 覆盖 0.65）
- 生成 `bili-cc-align` 候选，现场版/原本选中 CC 时优先选它；只有检测到 CC 是翻译（`ccTranslated`）或宽松匹配时才优先，避免中文歌反而丢掉完整 CC 原文
- 当前是行级 DP；还没有拼音/音素级对齐，也没有逐词时间
- 需要本视频有 CC 字幕且已登录

**还可继续加**：字符/拼音级 DP、CC 段落锚点约束、逐词时间分配

#### 6.2 本地 ASR（可选包）
- `sherpa-onnx-node` + SenseVoice int8（约 228MB）
- 按需下载，不默认打包
- worker/utilityProcess 运行，不阻塞 UI
- ASR token 时间 + 已知歌词 DP 对齐
- 置信度低于阈值标红，交给手动

**价值**：完全没歌词/现场版也能出时间轴  
**成本**：高  
**风险**：模型体积、首次下载、CPU 耗时、歌唱识别错误率

#### 6.3 更好的现场对齐特征
- 当前只用 onset 包络；可加：
  - 人声频段能量
  - chroma/调性
  - beat/downbeat
  - RANSAC/分段锚点
  - 用 CC 锚点约束 scale/offset
- 置信度校准，低置信不自动应用

**价值**：减少“对齐后全部越界/低置信”  
**成本**：中高  
**风险**：实现复杂度；需要真实样本回归

#### 6.4 云端 ASR（可选）
- 阿里 Paraformer（国内、便宜、10 小时/月免费）
- OpenAI whisper-1（海外）
- 只对单曲显式开启，显示费用/隐私提示

**价值**：不想装本地模型时的备选  
**成本**：中  
**风险**：API key、网络、隐私、费用

## 6. 优化方向

### 6.1 缓存与请求
- 搜索结果持久化（不只内存）
- 队列下一首预取 1–2 首（限速）
- 同歌并发请求合并（single-flight）
- 负缓存区分“真没有”和“风控失败”
- 缓存按 `bvid/cid/nid + 标题/时长` 失效
- 对齐结果缓存 + 版本号，规则升级后自动失效

### 6.2 性能
- 长歌词虚拟滚动（200+ 行）
- 逐字 DOM 数量限制/分段渲染
- 解析/对齐放 Worker
- 音频分析不要整首下载：分段/前奏+人声段
- 释放 AudioBuffer，限制缓存大小
- 低性能模式下降级逐字动画

### 6.3 匹配质量
- 歌手别名词典（夜鹿、真夜中、痛亲王等）
- 罗马音/假名/英文译名匹配
- 时长聚类 + 首行/末行时间验证
- 封面/标题/标签多信号
- 自动识别“翻唱/伴奏/片段/教学/鬼畜”并降权
- 候选源分数可解释（UI 显示）

### 6.4 工程
- 解析器单测：LRC/YRC/KRC/TTML/别名/版本
- 匹配回归集：固定标题样本 + 期望结果
- 现场对齐合成测试：已知 scale/offset 恢复
- 队列批量回归脚本
- Provider 接口抽象，便于加 QQ/其他源
- 本地诊断日志（不联网）
